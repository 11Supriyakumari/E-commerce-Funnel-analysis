# User Funnel Performance Dashboard

## Project Overview

This project analyzes customer behavior across the purchase funnel using Power BI.

The dashboard tracks:

- User Journey
- Funnel Conversion
- Revenue Performance
- Channel Effectiveness
- Device Analysis
- Regional Performance

## Business Objective

Identify where users drop off in the purchase funnel and discover opportunities to improve conversion rates and revenue.

## Key KPIs

- Total Users: 10,000
- Total Revenue: 277.32K
- Conversion Rate: 10.04%
- Drop-off Rate: 89.96%
- Total Purchases: 1,004

## Dashboard Features

### Executive Summary
- Funnel visualization
- Conversion metrics
- Revenue KPIs

### Marketing Analysis
- Revenue by channel
- Channel performance

### User Analysis
- Device-wise purchases
- Regional revenue distribution

### Funnel Analysis
- Browse → Cart
- Cart → Checkout
- Checkout → Purchase

## Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights

1. Overall conversion rate is 10.04%.
2. Major drop occurs between Checkout and Purchase.
3. Google Ads generates highest revenue.
4. Desktop users contribute highest purchases.
5. Revenue distribution is relatively balanced across regions.

## Business Recommendations

- Simplify checkout process.
- Improve mobile experience.
- Increase investment in high-performing channels.
- Implement cart abandonment campaigns.
